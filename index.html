      Hướng dẫn nhanh
      
  
        
    
      • Mở thư mục làm việc (Chrome/Edge): chọn thư mục trên máy. Các lệnh use, save, graph export, esttab using, outreg2, log using đọc/ghi thẳng vào thư mục đó.
        • 
    
      • Trình duyệt khác: kéo thả file vào trang hoặc dùng Tải file lên; tải kết quả bằng nút ⬇ trong Files hoặc Tải tất cả.
        • 
    
      • Đường dẫn Windows trong do-file (vd. D:\...\data.dta) tự quy về file cùng tên trong thư mục làm việc.
        • 
    
      • Dữ liệu chỉ xử lý trong trình duyệt của bạn, không gửi đi đâu.
        • 
    
      • Hỗ trợ các lệnh trong bộ do-file mẫu: RCT, IV (ivregress, ivreg2), DID (xtreg, reghdfe, didregress, csdid, sdid), PSM (psmatch2, teffects, kmatch), RDD (rdrobust, rdplot, rddensity), SCM (synth2), cùng lệnh dữ liệu, bảng (esttab, outreg2) và đồ thị.
        • 
    
      • Lưu ý: số ngẫu nhiên (rnormal, runiform) không trùng chuỗi của Stata, nên dữ liệu mô phỏng cho kết quả gần nhưng không giống hệt Stata.
